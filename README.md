# LMSBank

Sistema bancário desenvolvido em Python para fins acadêmicos, executado inteiramente via console. O projeto aplica conceitos de modularização, funções e estrutura de repetição.

## Funcionalidades
* Cadastro de cliente
* Consulta de saldo
* Realização de depósitos
* Realização de saques

## Estrutura do Projeto
* `main.py`: Arquivo principal que gerencia o menu e a interface no console utilizando laço de repetição (`for`).
* `cliente.py`: Módulo responsável pelas funções de cadastro.
* `conta.py`: Módulo responsável pelas regras lógica matemática (saldo, depósito e saque).
